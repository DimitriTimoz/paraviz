# Security Policy

## Reporting a Vulnerability

ParaViz parses untrusted scientific data files (VTK Legacy/XML, compressed streams, medical volumes, and mesh formats). If you discover a security vulnerability—such as a panic, out-of-bounds read, integer overflow, or memory exhaustion triggered by malformed input—please report it responsibly:

- **Do not** open a public issue with exploit details before a fix is available.
- Instead, use GitHub's private vulnerability reporting on [the repository's Security tab](https://github.com/DimitriTimoz/paraviz/security/advisories/new).

We aim to acknowledge reports promptly and coordinate a fix and release.
